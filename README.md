# Torneos eSports - Kotlin

Aplicación visual nativa para Android creada desde cero con Kotlin y Jetpack Compose.

## Incluye

- Inicio
- Perfil
- Galería
- Transmisiones
- Visor web visual
- Acciones del torneo
- Navegación lateral reutilizable
- Tema, colores y componentes compartidos

El proyecto contiene solamente la capa visual. Los botones no ejecutan lógica de negocio y no hay backend, autenticación, reproducción de video ni WebView.

## Abrir

Importa la carpeta como proyecto Gradle de Android. La compilación requiere Android SDK, JDK y acceso a las dependencias indicadas en Gradle.
